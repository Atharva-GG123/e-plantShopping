# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is a dynamic e-commerce shopping application for an online plant shop. The application allows users to browse plants organized by categories, view plant details with images and prices, add plants to their shopping cart, and manage cart items with ease.

## Features

### 1. Landing Page
- Welcoming hero section with company branding
- Call-to-action "Get Started" button
- Professional layout showcasing Paradise Nursery

### 2. Product Listing
- Browse plants organized into 3+ categories
- Display 6+ unique houseplants per category
- Each plant displays:
  - Thumbnail image
  - Plant name
  - Price
  - "Add to Cart" button
- Dynamic cart icon showing total items
- Responsive navbar with navigation links

### 3. Shopping Cart
- View all items added to cart
- Display for each item:
  - Thumbnail and plant name
  - Unit price
  - Quantity with increase/decrease buttons
  - Total cost for each item
- Overall cart total amount
- Delete button for each item
- "Continue Shopping" button to return to products
- "Checkout" button (displays "Coming Soon" message)

### 4. Navigation
- Navbar accessible from all pages
- Links to: Home, Plants, Cart
- Dynamic cart count indicator

## Technology Stack
- **Frontend:** React 18
- **Build Tool:** Vite
- **State Management:** Redux Toolkit
- **Routing:** React Router DOM
- **Styling:** CSS3

## Getting Started

### Installation


### Development
```bash

```

### Build
```bash

```
